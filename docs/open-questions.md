# Open questions

Spikes (`S`) and contradictions between sources (`C`) found while designing L3 and L4. Each has a discussion issue in milestone M0 with the label `question`, and a node in the [trace graph](traceability/README.md) delivered by that issue. A spike row stays here until its issue closes; the decision then moves into the design it names. A resolved contradiction keeps its row, with the ruling and the documents it moved into. Decided points are not repeated here: where the query embedder runs is decided (hub-side, D-009, SYS-071), and choosing its model and placement is the benchmark of TEST-091, not an open question.

> **Source legend.** As in [the tessera boundary](architecture/tessera-boundary.md). The "Proposed" option is the one the design uses until the issue is settled.

**Graph edges.** Each row names the design it concerns (the DES in parentheses). That link is not in the trace graph: ADR-0001's edge table allows only `delivered_by` from an `S` or `C` node (to its discussion issue), and no edge kind runs from an `S` or `C` node to a `DES`. Inventing one is not allowed, so the link lives in this table until a decision moves into the design it names.
