# L2: verification plan

One system `TEST` for each [system requirement](L2-system-requirements.md), each stating a method, an environment, a pass criterion with a number and how it is automated. A test is a specification until a slice implements it; the numbers inherit the *(estimate)* marks of the requirement they verify.

> **Source legend.** `XADR-SCITADEL-008` is the vig-os/scitadel decision record "scitadel-hub: a lab corpus server" (ADR 008, status Proposed, [pull request 317](https://github.com/vig-os/scitadel/pull/317)). Every identifier below is a node in the [trace graph](../traceability/README.md), checked by `tools/trace-check`.

## Environments

| Environment | What it is | Used for |
|---|---|---|
| CI | the repository's pipeline: hosted runner for public fixtures, the fleet runner for private ones | contract, lint, fixture and logic tests; minutes, small data |
| vm-dev | the interactive seat shared by every agent | **light work only**: a dry run, a lint, one small fixture. Never corpus-scale data, never a load test, build sweep or index build |
| ksb | the CPU batch host, used through `ksb run` | load tests, index builds and timing, golden-set runs, backup and restore checks on scratch images |
| anvil-gpu | anvil's shared GPU through `gpu_submit` | GPU smoke and throughput tests, declared VRAM, low priority, chunked to the default 30-minute runtime with checkpoints |
| anvil-microvm | microVM tenants on anvil (`microvm.nix`) | isolation, metering, restore and install drills on the packaging the hosted tier uses |

**No heavy job runs on vm-dev in any environment.** Every test whose method needs corpus-scale data, a load generator, an index build, a restore or a GPU names `ksb`, `anvil-gpu` or `anvil-microvm`; vm-dev appears only as a place for a light dry run, and only where a row says so.

**Automation.** *CI* runs on every pull request unless the row says otherwise. *Scheduled* runs on the stated cadence on ksb or in tenant simulation and reports to the observability seam. *Manual drill* is a human-run exercise on the stated cadence, logged in the repository.
